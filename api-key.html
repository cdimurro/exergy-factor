What the API Provides

One stream-calculation contract.

Discover the accepted inputs, then calculate energy quantity, Exergy Factor, and accessible exergy. The same JSON request works through Python, the CLI, and HTTP. 

GET  /v1/health
GET  /v1/capabilities
GET  /v1/calculate/schema
POST /v1/calculate
GET  /v1/accounting/schema
POST /v1/account

Install quantity-and-quality[api] and run quantity-quality serve-api for a local deployment, or use the hosted beta directly. Results retain units, reference conditions, basis, boundary, Fidelity Tier, assumptions, and warnings.
