Hosted Access Preview

Hosted API access is coming soon. The Python package and local API are available today.

What the API Provides

One stream-calculation contract.

Discover the accepted inputs, then calculate energy quantity, Exergy Factor, and accessible exergy. The same JSON request works through Python, the CLI, and HTTP. 

GET  /v1/capabilities
GET  /v1/calculate/schema
POST /v1/calculate
GET  /v1/accounting/schema
POST /v1/account
GET  /v1/schema
POST /v1/validate

Install quantity-and-quality[api] and run quantity-quality serve-api to evaluate these endpoints locally today. Public key requests remain disabled until the production service is live.
