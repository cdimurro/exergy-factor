Developer API

Use the free Exergy Factor API.

The public beta exposes the deterministic Quantity and Quality calculation kernel through HTTPS. No account or API key is required.

Base URL

https://exergy-factor-api.onrender.com/v1

The service is free to try and may sleep after inactivity. The first request after a sleep can take about a minute. For private, high-volume, or production workloads, run the package or the same container under your own account.

Read the hosted API terms before sending requests. Do not submit confidential, regulated, or personal data.

Open interactive API docs

Quick start

One request, auditable fields.

Responses retain units, reference conditions, basis, boundary, Fidelity Tier, assumptions, warnings, and notation. 

curl https://exergy-factor-api.onrender.com/v1/calculate \
  -H "Content-Type: application/json" \
  -d '{
    "stream_type": "heat",
    "quantity": 1,
    "unit": "MWh_th",
    "source_c": 80,
    "sink_c": 20
  }'

Available routes include /v1/capabilities, /v1/calculate, /v1/account, /v1/validate, and the generated OpenAPI schema.
